# ⚡ SpeedMaster for YouTube

YouTube playback speed controller with smart speed memory, custom playback controls, and intelligent ad acceleration.

---

## ✨ Features

### 🎬 Playback Controls
- Quick speed buttons:
  - `1x`
  - `2x`
  - `3x`
  - `5x`
- Custom playback speed input
- Active speed highlighting
- Persistent playback speed across videos
- Smooth modern UI integrated directly into YouTube player

---

### 🚀 Smart Ad Handling
- Automatically speeds up ads to `10x`
- Automatically mutes ads
- Restores original playback speed after ads
- Hides controls during ads for clean experience

---

### 🎨 Modern UI
- Premium glassmorphism design
- Smooth hover animations
- Responsive controls
- Minimal professional appearance

# 🛠 Installation Guide

## Step 1 — Download Project

Download or clone the repository:

```bash
https://github.com/tauqeeralam11/speedmaster-youtube-extension.git
```

Or download ZIP directly from GitHub.
after downloading, extract/unzip the ZIP file

---

## Step 2 — Open Chrome Extensions

Open Chrome and go to:

```text
chrome://extensions/
```

---

## Step 3 — Enable Developer Mode

Enable:

```text
Developer Mode
```

(top-right corner)

---

## Step 4 — Load Extension

Click:

```text
Load unpacked
```

Then select your project folder:

```text
speedmaster-youtube-extension/
```

---

## Step 5 — Open YouTube

Go to:

```text
https://youtube.com
```

You will now see:

- Playback speed controls
- Custom speed input
- Smart ad acceleration
- Premium UI integrated into player

---

# 🎯 Usage

## Default Speed Buttons

Click:
- `1x`
- `2x`
- `3x`
- `5x`

to instantly change playback speed.

---

## Custom Playback Speed

Use the custom input box:

```text
1.5
2.25
3.75
```

Then press:

```text
Enter
```

The extension will:
- apply speed instantly
- save it automatically
- create active custom speed button
